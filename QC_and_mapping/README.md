This directory contains all scripts used for quality checks and read-mapping.
All scripts were started in the order listed below.

## run_fastqc.sh
Running FastQC for raw sequencing data.

## run_bwa-mem2.sh
Do the read mapping with BWA-MEM2.

## run_stats.sh
Running samtools stats and mosdepth.

## only_mutliqc.sh
Create one MultiQC report.

## merge_bam.sh
Merge the two bam-files of the first and second sequencing run for two samples.
